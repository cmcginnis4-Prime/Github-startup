## How to add new references

1. Drop the image into the project folder (or `docs/milanote/`), keeping the original
   filename where possible. PDFs are fine but get rendered to a single page at reduced
   resolution, so export a PNG if detail matters.
2. Say which files are new and what each one is for: style anchor, production turnaround,
   drift-test output, panel template, failed generation, style inspiration, screenshot.
   Role is the one thing that cannot be inferred from the image itself.
3. Ask for the inventory to be updated. Each addition gets a row in the local table with
   *what it is* and *role*, plus a one-line description usable as alt text.
4. If the image is also going on the dashboard, say so at the same time so the alt text is
   written once.
5. When a file is renamed, note the original filename under the table so the source stays
   traceable.

Common roles: **style anchor**, **production turnaround**, **reference sheet**, **drift
failure**, **panel template**, **framing inspiration**, **screenshot / evidence**.
